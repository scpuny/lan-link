## 第十三轮：自定义窗体，区分 macOS / 非 macOS（§22）
- 用户要求：不要系统自带主窗体标题栏，改自定义窗体，并区分 macOS 与非 macOS。
- 问题：`tauri.conf.json` 未配 `decorations` → 原生标题栏 + 前端 `TitleBar.vue` 双标题栏；`.tb-win` 三键用 Electron 的 `-webkit-app-region`（Tauri 不识别）且无点击行为。
- 策略：**不统一 `decorations:false`**。macOS 用 `decorations:true` + `titleBarStyle:"Overlay"` + `hiddenTitle:true` + `trafficLightPosition{x:16,y:15}`，保留系统交通灯与圆角阴影（自绘无法复刻交通灯的 hover / 全屏 / 辅助功能语义）；Windows/Linux 用 `decorations:false` + 前端自绘三键。
- 配置分层：`tauri.conf.json`（基础）+ `tauri.macos.conf.json`（覆盖）。平台配置按 RFC 7396 合并、**数组整体替换**，所以 macos 文件必须重复完整 `windows` 数组（含 label/尺寸/min）。
- **关键坑（务必记住）**：`tauri dev -c tauri.conf.json` 的 `--config` 是「再合并一次」语义，会把主配置的 `windows`（`decorations:false`）盖回平台合并结果之上 → macOS 交通灯消失、圆角丢失、窗口变直角。**直接 `tauri dev`，不要带 `-c`**。
- 前端：新增 `composables/usePlatform.ts`（`userAgentData.platform` → `navigator.platform` → UA 正则三级回退，导出 `IS_MAC`；用 UA 是因为 `init()` 异步，标题栏首帧就要分支）。`TitleBar.vue`：`.titlebar.is-macos{padding-left:78px}` 给交通灯让位；非 macOS `v-if="!IS_MAC"` 渲染三键，绑定 `getCurrentWindow().minimize()/toggleMaximize()/close()`（仅 `bridgeMode==='tauri'` 执行）；删除 `-webkit-app-region`，改用 **`data-tauri-drag-region`**，且必须逐个标在 `header`/`.tb-left`/`.tb-center`/文本节点上（Tauri 只对带该属性的元素本身响应 mousedown），AppMenu 与窗口按钮不加。
- **权限**：项目原先没有 `capabilities/` 目录。Tauri v2 的 `core:window:default` 只含只读权限（is-*/get-*），`minimize / close / toggle-maximize / start-dragging` 必须显式授权，否则 IPC 被拒且**静默失败**。新增 `capabilities/default.json`，其中 `"windows":["main"]` 必须与窗口 `label:"main"` 对应。
- 窗口尺寸改为定版 `1180×820`（原 960×640），min `900×620`。
- 验证：`cargo check` 通过；`npm run build` **88 模块**；运行时探针 `[lanlink-window] decorated=Ok(true) size=2360×1642`（=1180×821@2x）；截图确认交通灯完整可见、与 logo 垂直居中、窗口为系统圆角、顶部为自绘标题栏。**Windows / Linux 分支未实机验证**。
